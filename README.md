# API Quest

API Quest is an interactive educational game for learning and practising REST APIs by building, sending, and debugging realistic HTTP requests.

- 🇬🇧 **English:** [Full documentation](./README_en.md)
- 🇪🇸 **Español:** [Documentación completa](./README_es.md)

## What is this repository?

The repository contains the complete static web game: 56 bilingual missions across seven chapters, a persistent fictional API Sandbox, progressive hints, XP, achievements, and browser-only progress.

The application uses React, TypeScript, and Vite. It does not require a backend or an account and does not send player data to an application server.
